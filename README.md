# Insidir engine

Backend-only financial disclosure ingestion and research API. **No website/design code in this repository.**

The engine is built around official SEC Form 4 ownership filings and source-backed, non-predictive research. It does not scrape restricted congressional financial disclosures, social networks, or digital-asset identities. Those providers require separate permissions and legal review before activation.

See `docs/ENGINE.md` for setup, API endpoints, deployment, and security guidance after installation.
