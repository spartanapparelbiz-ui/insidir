# Insidir Engine

**Backend-only financial intelligence infrastructure.** No design files or frontend changes.

- Real SEC Form 4 XML transaction parsing and verified source references
- PostgreSQL ingestion, deduplication, source dates and audit history
- APIs for filings, purchases/sales, company and insider searches, descriptive purchase clusters
- Account sessions and gated watchlist support
- Politician, social platform and crypto sources **disabled until legal and data permissions are verified**

[Setup, API and deployment documentation](docs/ENGINE.md) · [Environment template](.env.example)

This is a technical backend, not a complete commercial release or legal certification.
